# 05 配置与持久化

## 配置持久化机制

核心类：[`PdfViewerSettings`](../../src/main/java/com/aiden/plugin/viewpdf/settings/PdfViewerSettings.java)

- 实现接口：`PersistentStateComponent<PdfViewerSettings.StateData>`
- State 标注：
  - `@State(name = "PdfViewerSettings", storages = @Storage("pdf-viewer.xml"))`
- 含义：
  - 插件配置会被 IDE 写入配置目录中的 `pdf-viewer.xml`（具体位置取决于 IDE 版本与 OS）
  - StateData 是纯数据结构（POJO），由 IntelliJ 的序列化机制读写

## 事件驱动更新（MessageBus）

监听接口：[`PdfViewerSettingsListener`](../../src/main/java/com/aiden/plugin/viewpdf/settings/PdfViewerSettingsListener.java)

- Topic：`PdfViewerSettingsListener.TOPIC`
- `PdfViewerSettings` 中几乎每个 setter 都会在更新 state 后同步发布事件：
  - ToolWindow：[`PdfViewerToolWindowFactory`](../../src/main/java/com/aiden/plugin/viewpdf/ui/PdfViewerToolWindowFactory.java) 订阅并更新 UI/重渲染
  - Editor PDF Popup：[`EditorPdfPopupController`](../../src/main/java/com/aiden/plugin/viewpdf/popup/EditorPdfPopupController.java) 订阅并同步样式
  - Word Popup：[`WordPopupController`](../../src/main/java/com/aiden/plugin/viewpdf/popup/WordPopupController.java) 订阅并刷新展示

该模式的优势：

- UI 与配置解耦：配置变化会以事件广播，避免 UI 主动轮询
- 多入口一致性：Settings 页面、快捷键 Action、Popup 拖拽写回等都能通过同一通道同步

## 配置项分类（StateData）

`PdfViewerSettings.StateData` 字段较多，可按功能域理解。

### PDF（ToolWindow 与共用项）

- `pdfPath`：当前 PDF 文件路径
- `nightModeEnabled`：夜间模式开关
- `pdfBackgroundR/G/B`：ToolWindow PDF 背景色
- `pdfTextR/G/B`：夜间模式下用于 tone-map 的“文字色”
- `pdfZoomPercent`：缩放百分比（10–500）
- `renderBatchPageCount`：每批渲染页数（>=1）
- `pdfReadPositions: Map<String, Integer>`：按 PDF 路径存储滚动条位置（阅读进度）

### ToolWindow 布局与行为

- `autoShowPdfHoverSeconds`：悬停自动显示 PDF 的延迟秒数（-1 禁用，0 立即）
- `paneLeftPercent/paneMiddlePercent/paneRightPercent`：三栏比例（最终归一化为 100%）
- `thirdPaneVisible`：右侧固定代码区是否显示
- Project tree 样式：
  - `treeBackgroundR/G/B`
  - `treeTextR/G/B`
  - `treeFontSize`

### 编辑器 PDF Popup（浮动 PDF）

- `editorPopupWidth/editorPopupHeight`：默认弹框尺寸
- `editorPopupBorderVisible`：是否显示边框
- `editorPopupPdfBackgroundR/G/B`：弹框内 PDF 背景色
- `editorPopupPdfTextR/G/B`：弹框夜间 tone-map 用文字色
- `editorPopupOpacityPercent`：透明度（10–100）

### 背单词 Word Popup

- Style：
  - `wordPopupWidth/wordPopupHeight`
  - `wordPopupX/wordPopupY`
  - `wordPopupFontSize`
  - `wordPopupFontR/G/B`
  - `wordPopupOpacityPercent`
- Content display：
  - `wordPopupShowMeaning`
  - `wordPopupShowSentence`
  - `wordPopupShowSynonyms`
  - `wordPopupSentenceLimit`（1–5）

### 词库选择与学习状态

词库来源与选择：

- `wordBuiltinVocabularyBook`：默认内置书 id（如 `CET4luan_2`）
- `customVocabularyBooks: List<CustomVocabularyBookData>`：自定义书列表（书名 + JSONL 路径）
- `selectedVocabularyBookKey`：当前选中的书（见 06 章的 key 规则）
- `wordSourceBuiltinEnabled` / `wordSourceCustomPath`：历史字段（当前逻辑以 “selectedVocabularyBookKey + customVocabularyBooks” 为主）

词池与学习状态：

- `wordEntries: List<WordEntryData>`：当前生效词池（由 `WordLibraryLoader` 计算后写回）
- `wordLearningStates: Map<String, WordLearningStateData>`：按单词 key（小写）存储掌握状态、复习次数、时间戳等

## Settings UI：`PdfViewerConfigurable`

文件：[`PdfViewerConfigurable.java`](../../src/main/java/com/aiden/plugin/viewpdf/settings/PdfViewerConfigurable.java)

- `createComponent()`：动态搭建 Swing 表单（多个行面板）
- `reset()`：从 `PdfViewerSettings` 拉取值填充 UI
- `isModified()`：对比 UI 值与 Settings 值
- `apply()`：调用 Settings setter 写回，并触发 `WordLibraryLoader.reloadWordEntriesFromSettings(settings)`

自定义词汇书添加流程：

1. 用户输入书名与文件路径
2. 调用 `WordLibraryLoader.validateCustomJsonl(path)` 校验
3. 通过后将 `CustomVocabularyBookData` 放入 UI 临时列表
4. 用户点击 Apply 后写入 Settings
