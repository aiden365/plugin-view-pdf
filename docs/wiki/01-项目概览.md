# 01 项目概览

## 项目定位

本仓库是一个 IntelliJ Platform 插件工程，插件显示名为 **XCode Tools**（见 [`plugin.xml`](../../src/main/resources/META-INF/plugin.xml)），主要提供两类能力：

1. **PDF 阅读/伪装视图**：在 ToolWindow 中实现 “代码伪装视图 ↔ PDF 阅读视图” 的切换，并支持悬停自动切换与三栏布局。
2. **编辑器弹框能力**：
   - 编辑器内浮动 PDF 弹框（可调大小/透明度/边框，可拖动）
   - “背单词”悬浮框（词库加载、筛选、下一个单词、标记已学会）

## 工程类型与构建方式

- 构建系统：Gradle Kotlin DSL（[`build.gradle.kts`](../../build.gradle.kts)）
- 插件构建插件：`org.jetbrains.intellij.platform`（IntelliJ Platform Gradle Plugin）
- 目标 IDE：IntelliJ IDEA Community `2025.1`（构建脚本中 `create("IC", "2025.1")`）
- Java 版本：源码/目标 `21`
- 关键第三方库：Apache PDFBox `3.0.2`（PDF 渲染）

## 插件入口点（Extension Points）

插件的核心入口都在 [`plugin.xml`](../../src/main/resources/META-INF/plugin.xml) 中声明：

- `applicationService`：`PdfViewerSettings`（全局持久化配置/状态）
- `applicationConfigurable`：`PdfViewerConfigurable`（Settings UI）
- `postStartupActivity`：`WordLibraryStartupActivity`（IDE 启动后加载词库到 Settings）
- `toolWindow`：`PdfViewerToolWindowFactory`（创建 `XTools` ToolWindow）
- `actions`：菜单与快捷键入口（PDF 滚动/切换、编辑器 PDF 弹框、背单词悬浮框等）

## 源码目录结构（高层视角）

```
src/main/java/com/aiden/plugin/viewpdf
  actions/     # 菜单/快捷键入口（AnAction）
  popup/       # 编辑器内弹框（PDF、单词悬浮框）
  settings/    # 持久化配置 + Settings UI + 词库加载
  ui/          # ToolWindow UI、布局容器、PDF渲染面板、项目树
  PdfViewerKeys.java  # Project UserData Key（跨模块传递 controller）

src/main/resources
  META-INF/plugin.xml   # 插件注册与入口声明
  vocabularies/*.json   # 内置词库
```
