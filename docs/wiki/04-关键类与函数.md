## ToolWindow 装配入口：`PdfViewerToolWindowFactory`

文件：[`PdfViewerToolWindowFactory.java`](../../src/main/java/com/aiden/plugin/viewpdf/ui/PdfViewerToolWindowFactory.java)

### `createToolWindowContent(Project, ToolWindow)`

职责要点：

- 创建 `StealthSplitPanel` 与 `PdfViewerToolWindowController`
- `project.putUserData(PdfViewerKeys.CONTROLLER_KEY, controller)` 让 Actions 能访问 ToolWindow
- 将 `PdfViewerSettings` 的值推到 UI（颜色/比例/缩放/批渲染/阅读位置 handler 等）
- 订阅 `PdfViewerSettingsListener.TOPIC`：
  - `pdfPathChanged`：触发 `ensureLoaded(newPdfPath, nightMode)`
  - `nightModeChanged`：仅当 PDF 可见才重渲染
  - `zoomPercentChanged`：更新 zoom 并 `ensureLoaded(...)`
  - `renderBatchPageCountChanged`：更新 `pagesPerBatch`

## ToolWindow 交互控制：`PdfViewerToolWindowController`

文件：[`PdfViewerToolWindowController.java`](../../src/main/java/com/aiden/plugin/viewpdf/ui/PdfViewerToolWindowController.java)

### `togglePdfView()`

- 语义：同时切换 “是否允许自动切换（pdfToggleEnabled）” 与 “当前显示卡片（PDF/伪装）”
- 与 UI 的关系：
  - 通过 `splitPanel.setPdfToggleEnabled(...)` 控制悬停切换逻辑是否生效
  - 通过 `splitPanel.showPdf()`/`splitPanel.showDisguise()` 控制可见卡片

### `scrollPdfByViewport(boolean down)`

- 代理到 `pdfPanel.scrollByViewport(down)`
- Action 层会用 `controller.isPdfVisible()` 决定是否允许滚动

## 布局容器：`StealthSplitPanel`

文件：[`StealthSplitPanel.java`](../../src/main/java/com/aiden/plugin/viewpdf/ui/StealthSplitPanel.java)

### `showPdf()` / `showDisguise()`

- `showPdf()`：
  - 将中间卡片切到 PDF，并设置背景色
  - 启动 `pdfLeaveWatchTimer`：检测指针离开 PDF 区域后自动回到伪装
- `showDisguise()`：
  - `pdfViewerPanel.saveReadingPositionNow()` 保存阅读位置
  - 停止 hover/pointer 检测，切回伪装

### `setPaneRatios(left, middle, right)` 与 `installPaneRatioPersistence()`

- 分栏比例会被持久化到 `PdfViewerSettings`：
  - divider 拖动触发 property change
  - 读取当前宽度计算比例，并调用 `settings.setPaneRatios(...)`

### `setAutoShowPdfCallback(...)`

- ToolWindow 工厂会将其设置为 “自动 ensureLoaded 当前 PDF”
- 配合 hoverTimer 形成 “悬停自动切换并加载”

## PDF 渲染核心：`PdfViewerPanel`

文件：[`PdfViewerPanel.java`](../../src/main/java/com/aiden/plugin/viewpdf/ui/PdfViewerPanel.java)

### `ensureLoaded(pdfPath, nightModeEnabled)`

- 仅当 `shouldReload(...)` 判断为需要重载才调用 `reload(...)`
- `shouldReload` 的触发条件包括：
  - 从未渲染过
  - PDF path 变更
  - nightMode 变更
  - zoom 变更
  - textColor 变更
  - nightMode 下 backgroundColor 变更

### `reload(pdfPath, nightModeEnabled)`

关键行为：

- 取消正在进行的渲染 worker 与阅读位置恢复 timer
- 保存当前阅读位置（避免切换时丢失）
- 规范化路径并校验文件是否存在
- 显示 “正在加载 PDF...”
- `startRenderBatch(file, startPage=0, seq, firstBatch=true)`

### `startRenderBatch(file, startPage, seq, firstBatch)`

实现方式：

- 使用 `SwingWorker<BatchRenderResult, Void>` 后台渲染
- 每批渲染 `[startPage, startPage + pagesPerBatch)` 的图片
- NightMode 下对图片进行 `toToneMap(...)`
- `done()` 回到 EDT 更新 UI：
  - 追加页面 `addPage(image)`
  - 第一批渲染后触发 `restoreReadingPosition()`
  - 滚动到阈值附近会 `maybeRequestNextBatch()`

### `setReadingPositionHandlers(loader, saver)`

外部注入持久化策略：

- ToolWindow：在 `PdfViewerToolWindowFactory` 中注入到 `PdfViewerSettings.pdfReadPositions`
- Editor Popup：在 `EditorPdfPopupController` 中注入到 controller 内存 Map

## Settings：`PdfViewerSettings`

文件：[`PdfViewerSettings.java`](../../src/main/java/com/aiden/plugin/viewpdf/settings/PdfViewerSettings.java)

### `getInstance()`

- 使用 `ApplicationManager.getApplication().getService(...)` 获取 Application 级服务

### setter 的共同模式

典型逻辑：

1. 归一化输入（trim、范围 clamp、空串转 null）
2. 若值未变化则 return
3. 写入 `state`
4. 通过 MessageBus 发送事件：
   - `ApplicationManager.getApplication().getMessageBus().syncPublisher(PdfViewerSettingsListener.TOPIC).xxxChanged(...)`

这使得 UI/controller 能用 “订阅事件” 的方式保持与设置一致，而不是主动轮询。

## 词库加载：`WordLibraryLoader`

文件：[`WordLibraryLoader.java`](../../src/main/java/com/aiden/plugin/viewpdf/settings/WordLibraryLoader.java)

### `reloadWordEntriesFromSettings(settings)`

- 调用 `loadMergedWordEntries(settings)`
- 将结果写回 `settings.setWordEntries(...)`

### `loadMergedWordEntries(settings)`

根据 `settings.getSelectedVocabularyBookKey()` 决定数据源：

- `builtin:<bookId>`：从资源 `vocabularies/<bookId>.json` 按行扫描提取
- `custom:<bookName>`：找到同名自定义词汇书，按 JSON Lines 按行提取
- `system:mastered`：把所有词条汇总后过滤出已掌握（`settings.isWordMastered(word)`）

备注：实现使用大量正则从每行 JSON 文本中提取字段，而不是 JSON parser，因此格式变化会直接影响解析结果。

## 背单词：`WordPopupController`

文件：[`WordPopupController.java`](../../src/main/java/com/aiden/plugin/viewpdf/popup/WordPopupController.java)

### `toggle(editor)` / `show(editor)` / `hide()`

- `toggle`：根据 popup 是否存在决定 show/hide
- `show`：
  - 刷新词池：`refreshWordPool(true)`
  - 创建 JBPopup 并展示在 `editor.getContentComponent()` 上
  - attach window tracking，用于位置/大小变化写回 settings

### `showNextWord()`

- 循环寻找下一个 “未掌握” 单词（`findNextIndexSkippingMastered`）
- 若全部掌握，则回退到顺序切换策略

### `markCurrentWordMasteredAndAdvance()`

- `PdfViewerSettings.toggleWordMastered(current.word)` 切换掌握状态
- 重载词池后尝试跳到下一个未掌握单词
