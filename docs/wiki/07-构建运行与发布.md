# 07 构建运行与发布

本项目是 IntelliJ Platform 插件工程，推荐使用 Gradle Wrapper 完成构建、调试与打包。

## 环境要求

- JDK：21（项目 `build.gradle.kts` 中设置 `sourceCompatibility/targetCompatibility = 21`）
- Gradle：使用仓库自带 wrapper（`gradlew` / `gradlew.bat`）

## 常用 Gradle 任务

以下任务来自 `gradlew.bat tasks --all` 的实际输出：

- 运行与调试：
  - `runIde`：启动沙盒 IDE，并加载当前插件（最常用）
- 打包与校验：
  - `buildPlugin`：构建插件并打包为 ZIP
  - `verifyPlugin`：运行 IntelliJ Plugin Verifier（检查二进制兼容性）
  - `verifyPluginStructure`：校验 `plugin.xml` 与插件结构完整性
- 构建：
  - `build` / `assemble` / `compileJava` / `compileKotlin`

## 本地调试（启动沙盒 IDE）

在仓库根目录执行：

```powershell
.\gradlew.bat runIde
```

启动后：

1. 打开 ToolWindow：底部 `XTools`
2. 进入 Settings：
   - Settings/Preferences → `XCode Tools`
   - 配置 PDF 文件路径（必须为 `.pdf`）
3. 在 ToolWindow 或编辑器中使用快捷键/菜单触发功能：
   - ToolWindow 中切换 PDF：`Ctrl + Alt + End`
   - 打开编辑器 PDF 弹框：ToolsMenu → `Show Editor PDF Popup`
   - 背单词悬浮框：`Ctrl + Alt + W`

## 使用 IDE 运行配置

仓库内包含 IntelliJ 的运行配置：

- [`.run/Run IDE with Plugin.run.xml`](../../.run/Run%20IDE%20with%20Plugin.run.xml)

在 IntelliJ IDEA 中打开工程后，可直接选择该配置运行，效果等同于 `runIde`。

## 打包插件（ZIP）

```powershell
.\gradlew.bat buildPlugin
```

产物位置通常在：

- `build/distributions/*.zip`

## 发布与签名（可选）

工程已启用 IntelliJ Platform Gradle Plugin，具备标准任务：

- `signPlugin`：Marketplace ZIP Signer 签名
- `publishPlugin`：发布到 JetBrains Marketplace

注意：签名/发布需要额外配置证书、token 等敏感信息，建议通过本地环境变量或私有 CI 变量注入，不要提交到仓库。
