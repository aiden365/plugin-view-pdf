# 03 模块划分

本章以包结构为主线描述主要模块的职责、边界与典型调用方式。

## `com.aiden.plugin.viewpdf`

### `PdfViewerKeys`

文件：[`PdfViewerKeys.java`](../../src/main/java/com/aiden/plugin/viewpdf/PdfViewerKeys.java)

职责：

- 定义 `Project` 级别的 `UserData Key`，用于在 Action 与 UI/controller 之间传递引用
- 避免全局单例污染，并使 “每个 Project 一个控制器实例” 成为默认模式

Key 列表：

- `CONTROLLER_KEY`：`PdfViewerToolWindowController`（ToolWindow 主控制器）
- `EDITOR_POPUP_CONTROLLER_KEY`：`EditorPdfPopupController`
- `WORD_POPUP_CONTROLLER_KEY`：`WordPopupController`

## `com.aiden.plugin.viewpdf.ui`（ToolWindow UI）

### `PdfViewerToolWindowFactory`

文件：[`PdfViewerToolWindowFactory.java`](../../src/main/java/com/aiden/plugin/viewpdf/ui/PdfViewerToolWindowFactory.java)

职责：

- ToolWindow 内容创建与装配（相当于 UI composition root）
- 从 `PdfViewerSettings` 读取配置并初始化 UI
- 订阅 `PdfViewerSettingsListener.TOPIC`，将配置变化“推送”到 UI/渲染层
- 将 `PdfViewerToolWindowController` 写入 `Project` UserData，供 Actions 调用

### `StealthSplitPanel`

文件：[`StealthSplitPanel.java`](../../src/main/java/com/aiden/plugin/viewpdf/ui/StealthSplitPanel.java)

职责：

- 三栏布局容器：
  - 左：`ProjectTreePanel`
  - 中：`CardLayout`（`DisguisePanel`/`PdfViewerPanel`）
  - 右：固定 `DisguisePanel`（可隐藏）
- 管理 “伪装 ↔ PDF” 的切换、自动悬停触发、离开 PDF 区域自动回退
- 将分栏比例写回 `PdfViewerSettings`（可持久化）

### `PdfViewerPanel`

文件：[`PdfViewerPanel.java`](../../src/main/java/com/aiden/plugin/viewpdf/ui/PdfViewerPanel.java)

职责：

- 负责 PDF 加载/渲染/分页批量加载/阅读位置保存与恢复
- 负责滚动条样式（Slim scrollbar）与拖拽平移（drag-pan）
- 对上游暴露的核心 API：
  - `ensureLoaded(pdfPath, nightMode)` / `reload(...)`
  - `scrollByViewport(down)`
  - `setZoomPercent(...)`、`setTextColor(...)`、`setBackgroundColor(...)`
  - `setRenderBatchPageCount(...)`
  - `setReadingPositionHandlers(loader, saver)`

### `DisguisePanel`

文件：[`DisguisePanel.java`](../../src/main/java/com/aiden/plugin/viewpdf/ui/DisguisePanel.java)

职责：

- 将选中的 `VirtualFile` 以只读 Editor 形式展示（目前仅对 `.java` 文件生效）
- 支持将 hover 监听绑定到 root/editor/content 组件，以配合 `StealthSplitPanel` 的 “悬停切换”

### `ProjectTreePanel`

文件：[`ProjectTreePanel.java`](../../src/main/java/com/aiden/plugin/viewpdf/ui/ProjectTreePanel.java)

职责：

- 基于 `VirtualFile` 构造轻量级项目树（惰性加载子目录）
- 点击文件节点时回调 `Consumer<VirtualFile>`，由上层决定如何渲染
- 提供可配置的树背景色/文字色/字体大小

### `PdfViewerToolWindowController`

文件：[`PdfViewerToolWindowController.java`](../../src/main/java/com/aiden/plugin/viewpdf/ui/PdfViewerToolWindowController.java)

职责：

- 封装 ToolWindow 对外暴露的操作入口，给 Actions 调用：
  - `togglePdfView()`、`closePdfView()`
  - `scrollPdfByViewport(down)`
- 维护当前 ToolWindow 是否正在显示 PDF 的状态（`pdfVisible`）

## `com.aiden.plugin.viewpdf.actions`（菜单/快捷键入口）

职责边界：

- 不直接持有 UI 实例，统一通过 `Project.getUserData(PdfViewerKeys.CONTROLLER_KEY)` 获取控制器
- 在 `update(...)` 中控制 Action 可用性与显示文本

典型 Action：

- `ClosePdfViewAction`：切换 ToolWindow 的 PDF/伪装，并触发 `ensureLoaded`
- `ScrollPdfUpAction`/`ScrollPdfDownAction`：视口级滚动（仅当 PDF 可见时可用）
- `ShowEditorPdfPopupAction`：打开编辑器 PDF 弹框
- `ToggleWordPopupAction`/`NextWordAction`/`MarkWordMasteredAction`：背单词相关

## `com.aiden.plugin.viewpdf.popup`（编辑器弹框）

### `EditorPdfPopupController`

文件：[`EditorPdfPopupController.java`](../../src/main/java/com/aiden/plugin/viewpdf/popup/EditorPdfPopupController.java)

职责：

- 管理编辑器内 PDF 弹框（JBPopup）的生命周期与样式同步
- 使用内部 `PdfViewerPanel` 复用 PDF 渲染能力
- 维护 session 内阅读位置（不写入全局配置）

### `WordPopupController`

文件：[`WordPopupController.java`](../../src/main/java/com/aiden/plugin/viewpdf/popup/WordPopupController.java)

职责：

- 管理背单词悬浮框（JBPopup）生命周期
- 从 `PdfViewerSettings.getWordEntries()` 取词池，并支持顺序切换与过滤后刷新
- 标记掌握状态写入 `PdfViewerSettings`，并触发词池重载

## `com.aiden.plugin.viewpdf.settings`（配置/持久化/词库）

### `PdfViewerSettings`

文件：[`PdfViewerSettings.java`](../../src/main/java/com/aiden/plugin/viewpdf/settings/PdfViewerSettings.java)

职责：

- `PersistentStateComponent`：将配置持久化到 `pdf-viewer.xml`
- 对外提供强类型 getter/setter，并通过 `MessageBus` 广播变更事件（`PdfViewerSettingsListener.TOPIC`）
- 保存以下数据：
  - PDF 路径、夜间模式、颜色、缩放、批量渲染页数、分栏比例、阅读位置等
  - 编辑器 PDF Popup：大小、边框、背景/文字色、透明度等
  - Word Popup：位置、大小、字体、透明度、显示项（释义/例句/同近义）等
  - 词库：内置/自定义书、当前选中书、词条列表、已掌握状态等

### `PdfViewerConfigurable`

文件：[`PdfViewerConfigurable.java`](../../src/main/java/com/aiden/plugin/viewpdf/settings/PdfViewerConfigurable.java)

职责：

- 在 IDE Settings 中提供 “XCode Tools” 配置界面
- 支持添加自定义词汇书（校验 JSON Lines 格式后加入列表）
- 在 `apply()` 时调用 `PdfViewerSettings` 更新，并触发 `WordLibraryLoader.reloadWordEntriesFromSettings(...)`

### `WordLibraryLoader`

文件：[`WordLibraryLoader.java`](../../src/main/java/com/aiden/plugin/viewpdf/settings/WordLibraryLoader.java)

职责：

- 加载内置词库（资源目录 `vocabularies/*.json`）与自定义词库（本地 JSON Lines 文件）
- 提供自定义词库校验：`validateCustomJsonl(path)`
- 根据 Settings 当前选中词汇书计算词池：`loadMergedWordEntries(settings)`
- 提供 “系统 - 已学会” 词汇书视图：`system:mastered`

### `WordLibraryStartupActivity`

文件：[`WordLibraryStartupActivity.java`](../../src/main/java/com/aiden/plugin/viewpdf/settings/WordLibraryStartupActivity.java)

职责：

- IDE 启动后触发一次 `WordLibraryLoader.reloadWordEntriesFromSettings(PdfViewerSettings.getInstance())`
