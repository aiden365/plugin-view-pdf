## 词汇书 Key 规则（selectedVocabularyBookKey）

Settings 中使用 `selectedVocabularyBookKey` 表示“当前选中词汇书”，在 `WordLibraryLoader` 中按 prefix 分流：

- `builtin:<bookId>`：内置词汇书（资源目录 `src/main/resources/vocabularies`）
- `custom:<bookName>`：自定义词汇书（本地文件，JSON Lines）
- `system:mastered`：系统虚拟书，展示所有来源中被标记为“已学会”的单词集合

## 内置词库（resources/vocabularies）

目录：[`src/main/resources/vocabularies`](../../src/main/resources/vocabularies)

包含文件（见目录说明 [`readme.md`](../../src/main/resources/vocabularies/readme.md)）：

- `CET4luan_2.json`、`CET6_2.json`、`KaoYan_2.json`、`GRE_2.json`、`IELTSluan_2.json`、`TOEFL_2.json`、`Level4luan_2.json`、`Level8luan_2.json`

加载方式：

- `WordLibraryLoader.loadVocabularyBookEntries(bookId)` 会读取 `vocabularies/<bookId>.json`
- 实现为“逐行读取 + 正则提取字段”（不是 JSON parser）
- 主要提取字段：
  - 单词：`"headWord": "..."`（HEAD_WORD_PATTERN）
  - 释义：从 `trans[].tranCn` 汇总得到（TRAN_CN_PATTERN + TRANS_OBJECT_PATTERN）
  - 音标：`usphone` 优先，其次 `ukphone`
  - 例句：从 `sentence.sentences[].sContent` 抽取英文句子
  - 同近义：从 `syno.synos[].hwds[].w` 抽取并按 `pos` 分组

因此，如果将内置词库替换为不同结构的 JSON，解析将直接失效。

## 自定义词库（JSON Lines）

自定义词库通过 Settings UI 添加（“校验并添加”），底层校验/解析逻辑在：

- `WordLibraryLoader.validateCustomJsonl(path)`
- `WordLibraryLoader.loadCustomJsonlEntries(bookName, path)`

### 文件格式要求（最低要求）

必须为“每行一个 JSON 对象”（可用 `.json` 或 `.jsonl` 后缀；UI 当前只允许选择 `json` 扩展名，但内容语义是 JSON Lines）。

每行至少要包含：

- `word`：单词
- `trans`：数组，至少包含一个元素，并且元素中要有 `tranCn`
- `pos` 可选（若缺失会使用 “释义” 作为类别名）

示例（每行一条）：

```json
{"word":"cancel","trans":[{"pos":"vt","tranCn":"取消；撤销"},{"pos":"n","tranCn":"取消"}]}
{"word":"persist","trans":[{"pos":"vi","tranCn":"持续；坚持"}]}
```

解析细节说明：

- 解析同样使用正则从每行文本中提取字段：
  - `WORD_PATTERN`：`"word": "..."`（必需）
  - `TRANS_OBJECT_PATTERN`：匹配带 `tranCn` 的对象片段
  - `TRAN_CN_PATTERN`：`"tranCn": "..."`
  - `POS_PATTERN`：`"pos": "..."`
- 若行为空行会被跳过
- 若缺失必要字段，会被计为 invalid 并在校验结果中给出样例行号

## “系统 - 已学会”词汇书

Key：`system:mastered`（见 `WordLibraryLoader.getSystemMasteredBookKey()`）

实现方式：

1. 汇总所有内置书 + 自定义书的词条（按 `word` 小写去重）
2. 用 `PdfViewerSettings.isWordMastered(word)` 过滤出已学会
3. 作为一个虚拟书返回给 UI 下拉框使用

## 学习状态（mastered / reviewCount / lastReviewedAt）

存储位置：`PdfViewerSettings.wordLearningStates: Map<String, WordLearningStateData>`

- key：`word` 的小写形式
- `toggleWordMastered(word)` 会：
  - 切换 `mastered` 值
  - 更新 `lastReviewedAtEpochMillis`
  - `reviewCount += 1`
  - 调用 `WordLibraryLoader.reloadWordEntriesFromSettings(this)` 重算当前词池

## 悬浮框显示内容控制

`WordPopupController.refreshContent()` 会根据 `PdfViewerSettings` 控制显示：

- `isWordPopupShowMeaning()`：显示/隐藏释义
- `isWordPopupShowSentence()`：显示/隐藏例句（英文）
- `isWordPopupShowSynonyms()`：显示/隐藏同近义
- `getWordPopupSentenceLimit()`：例句最多显示 1–5 条
