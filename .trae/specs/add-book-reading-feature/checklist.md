- [x] ToolWindow 底部存在“图书管理”栏目，且默认不显示
- [x] 可通过 ToolWindow 顶部功能按钮显示/隐藏“图书管理”栏目
- [x] “图书管理”栏目内存在图书列表区域，且列表为两列（书名、操作）
- [x] 图书列表顶部提供“导入图书”“添加图书”按钮与书名搜索框
- [x] “导入图书”可选择 txt 文件导入，文件名（不含扩展名）作为书名，并处理重名
- [x] “添加图书”弹框可输入书名与正文内容（文本域），提交后可出现在列表中
- [x] 图书列表操作列提供“编辑”能力：导入图书可重新导入；手动图书可回显编辑并提供取消/保存
- [x] 搜索功能可按书名进行模糊匹配过滤（大小写不敏感）
- [x] 可在图书列表操作栏切换当前阅读图书
- [x] 可在设置面板切换当前阅读图书，且与 ToolWindow 状态同步
- [x] 选择图书后，会将该书第一行内容输出到 IDE 底部通知栏（Event Log）
- [x] 提供“上一行”“下一行”快捷键，触发后输出对应行到通知栏并更新阅读位置
- [x] 阅读位置按图书维度持久化，重启 IDE 后可从上次阅读位置继续
