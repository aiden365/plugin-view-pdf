- [ ] 在编辑器内可通过快捷键唤起 Lookup，Esc 可关闭且不改变文档内容
- [ ] Lookup 列表始终固定 4 项且顺序固定：当前单词、Next、Prev、Learn
- [ ] 输入任意字母/数字/符号不会触发过滤、不会插入、不会改变列表
- [ ] Enter 执行任意项均不会向文档插入单词或命令文本
- [ ] Next 可切换到下一个单词并刷新 Lookup；到边界时循环
- [ ] Prev 可切换到上一个单词并刷新 Lookup；到边界时循环
- [ ] Next/Prev 优先跳过已学会单词；若全部已学会则退化为正常循环
- [ ] Learn 可切换当前单词已学会状态并持久化，且停留当前单词、Lookup 保持打开
- [ ] 无可学习单词时第 1 项显示“暂无可学习单词”，Next/Prev/Learn 执行无副作用
- [ ] 新功能不影响 IDE 正常补全：仅在用户触发该动作时出现并拦截输入
